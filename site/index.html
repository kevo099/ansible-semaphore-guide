    Where will the controller run?
    Which system will the VM run?

    The account you log in to the VM with, which can use sudo. It will own the guide's folder and the lab folder.

    Access

    Semaphore's web UI listens on the VM itself only. Choose how your browser reaches it; you can change it later with one command.

    How will you open Semaphore?

    An IPv4 address or a DNS name, which the certificate will name. Leave it empty to use the VM's own address. On a cloud VM behind NAT, as on Azure, that is the private address.
